# PWA化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `apps/web`をオフラインでも動作し、ホーム画面/アプリ一覧からインストールできるPWAにする。

**Architecture:** `vite-plugin-pwa`（`generateSW`戦略）を`apps/web/vite.config.ts`に追加し、ビルド成果物全体（JS/CSS/HTML/PGliteのwasm/data・アイコン、約18MB）をWorkboxのprecacheマニフェストに載せる。Web App Manifestもこのプラグインが生成する。既存の`favicon.svg`から正方形の各種PNGアイコンを起こし、`apps/web/src/pwa/UpdateBanner.tsx`が`virtual:pwa-register/react`の`useRegisterSW`フックを使って「更新があります」バナーを出し、クリックで明示的に新しいService Workerへ切り替える。

**Tech Stack:** TypeScript, React, Vite, vite-plugin-pwa（Workbox）, Playwright（既存構成 + 新規devDependency 1つ）

## Global Constraints

- 設計書: `docs/superpowers/specs/2026-08-09-pwa-design.md`（承認済み）
- Service Workerは`vite-plugin-pwa`の`generateSW`戦略を使う（`injectManifest`や手動SW実装はしない）
- `workbox.maximumFileSizeToCacheInBytes`をデフォルトの2MiBから引き上げる — `pglite-*.wasm`(約10MB)・`pglite-*.data`(約6.3MB)がデフォルト上限のままだとprecacheから黙って漏れ、「オフラインだとSQL実行だけ動かない」という壊れ方をする。これが今回の最重要の落とし穴
- `registerType: "prompt"` — 新しいビルドを自動即時反映しない。反映は`UpdateBanner`からのユーザー操作でのみ行う
- `theme_color: "#1d4ed8"` / `background_color: "#f6f5f0"`（既存CSSのライトモード配色`--key`/`--paper`と一致させる）
- ダークモード時のsplash背景色の出し分けはWeb App Manifestの仕様上不可。対象外とし対応しない
- 独自のインストール促進UI（`beforeinstallprompt`を使ったカスタムボタンなど）は対象外。ブラウザ/OS標準のインストール導線に任せる
- `wrangler.jsonc`は変更しない（新規静的ファイルは既存の`assets`バインディングでそのまま配信される想定）
- `curl`・`wget`は使用禁止（ユーザーのグローバル設定）。HTTPレスポンスヘッダーの確認が必要な場合はNode組み込みの`fetch`かブラウザのDevTools経由で行う
- `UpdateBanner`はブラウザAPI/サードパーティフックへの薄いラッパーで抽出できる純粋ロジックがないため、本プロジェクトの既存方針（`TerminalView`と同様）どおりユニットテスト対象にはしない。ビルド・lint・既存テストのグリーンと、最終タスクでの手動ブラウザ確認でカバーする

- [ ] **Step 1: 一時生成スクリプトを作成する — リポジトリ直下 `tmp-gen-icons.mjs`（コミット対象外）**

```js
import { mkdirSync, readFileSync } from "node:fs";
import { chromium } from "@playwright/test";

const svg = readFileSync("apps/web/public/favicon.svg", "utf8");

const specs = [
  { name: "icon-192", size: 192, logoScale: 0.7 },
  { name: "icon-512", size: 512, logoScale: 0.7 },
  { name: "icon-maskable-192", size: 192, logoScale: 0.45 },
  { name: "icon-maskable-512", size: 512, logoScale: 0.45 },
  { name: "apple-touch-icon", size: 180, logoScale: 0.7 },
];

mkdirSync("apps/web/public/icons", { recursive: true });

const browser = await chromium.launch();
const page = await browser.newPage();

for (const { name, size, logoScale } of specs) {
  const logoWidth = Math.round(size * logoScale);
  await page.setViewportSize({ width: size, height: size });
  await page.setContent(`<!doctype html>
<html>
<head>
<style>
  html, body { margin: 0; padding: 0; }
  .canvas {
    width: ${size}px;
    height: ${size}px;
    background: #f6f5f0;
    display: flex;
    align-items: center;
    justify-content: center;
  }
  .canvas svg { width: ${logoWidth}px; height: auto; }
</style>
</head>
<body>
  <div class="canvas">${svg}</div>
</body>
</html>`);
  await page.locator(".canvas").screenshot({ path: `apps/web/public/icons/${name}.png` });
}

await browser.close();
```

```ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import { VitePWA } from "vite-plugin-pwa";

// https://vite.dev/config/
export default defineConfig({
  plugins: [
    react(),
    VitePWA({
      registerType: "prompt",
      devOptions: {
        enabled: true,
        type: "module",
      },
      manifest: {
        name: "SQL学習アプリ",
        short_name: "SQL学習",
        description: "ブラウザ完結のSQL学習ターミナル",
        lang: "ja",
        display: "standalone",
        start_url: "/",
        scope: "/",
        theme_color: "#1d4ed8",
        background_color: "#f6f5f0",
        icons: [
          { src: "/icons/icon-192.png", sizes: "192x192", type: "image/png", purpose: "any" },
          { src: "/icons/icon-512.png", sizes: "512x512", type: "image/png", purpose: "any" },
          { src: "/icons/icon-maskable-192.png", sizes: "192x192", type: "image/png", purpose: "maskable" },
          { src: "/icons/icon-maskable-512.png", sizes: "512x512", type: "image/png", purpose: "maskable" },
        ],
      },
      workbox: {
        globPatterns: ["**/*.{js,css,html,wasm,data,svg,png,ico}"],
        // Workboxのデフォルト上限は2MiB。pglite-*.wasm(約10MB)・pglite-*.data(約6.3MB)が
        // 黙ってprecacheから漏れ、オフライン時にSQL実行だけ動かなくなるのを防ぐため引き上げる。
        maximumFileSizeToCacheInBytes: 20 * 1024 * 1024,
        navigateFallback: "/index.html",
      },
    }),
  ],
});
```

```tsx
import { useRegisterSW } from "virtual:pwa-register/react";

export function UpdateBanner() {
  const {
    needRefresh: [needRefresh],
    updateServiceWorker,
  } = useRegisterSW();

  if (!needRefresh) return null;

  return (
    <div className="update-banner" role="status">
      <span>更新があります</span>
      <button type="button" className="update-banner__button" onClick={() => updateServiceWorker(true)}>
        再読み込み
      </button>
    </div>
  );
}
```
